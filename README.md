# “Personal Computer”
The PC assembly service creates ready-made configurations, including the processor, graphics card, and other components. 
Components are created only within the assembly process and do not exist outside of it.

## Structure
 - main.py - main file of the application 'Personal Computer'
 - hardware.py - describe hardware components of the computer
 - personal_computer.py - describe personal computer

## Installation

1) Clone repository
```
git clone https://github.com/Ivanmatv/personal_computer.git
```
2) Change directory
```
cd personal_computer
```

## Usage 

Launch the application
```
python main.py
```

## Result 

After lunch application, you receive message in the terminal
```
{'Model': 'Apple', 'Cell': [AMD, 3.3 GHz], 'Video Card': [Nvidia, 16 GB], 'Hard Driver': [Samsung, 512 GB]}
```
